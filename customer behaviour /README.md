# Customer Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI. The goal is to transform raw customer transaction data into meaningful business insights and visualize key trends through an interactive dashboard.

## 🛠️ Tools Used

* Python (Pandas)
* SQL Server / MySQL
* Power BI
* GitHub

## 🔄 Project Workflow

### 1. Data Preparation & EDA (Python)

* Imported and explored the dataset
* Cleaned missing and duplicate data
* Connected Python to SQL Database
* Loaded cleaned data into SQL

### 2. SQL Analysis

Business questions answered using SQL:

* Total revenue by gender
* Customers who used discounts but spent above average
* Top 5 highest-rated products
* Average purchase amount by shipping type
* Spending comparison of subscribers vs non-subscribers
* Products with the highest discount usage
* Customer segmentation (New, Returning, Loyal)
* Top 3 products in each category
* Relationship between repeat buyers and subscriptions
* Revenue contribution by age group

### 3. Power BI Dashboard

* Connected SQL database to Power BI
* Created interactive visualizations
* Built KPI cards, charts, and filters
* Analyzed customer, product, and revenue trends

### 4. Report & Presentation

* Prepared a project report summarizing findings
* Created a presentation deck with key insights and recommendations

## 📊 Key Insights

* Identified high-value customer segments
* Analyzed the impact of discounts on purchases
* Compared subscriber and non-subscriber spending behavior
* Determined top-performing products and categories
* Evaluated customer loyalty and repeat purchase patterns
