# 🍕 Pizza Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes pizza sales data to uncover business insights and visualize key performance indicators using **MySQL** and **Power BI**. The objective is to transform raw transactional data into actionable insights that support data-driven decision-making.

The project follows a complete analytics workflow, including data exploration, SQL-based analysis, database integration, KPI generation, and interactive dashboard development.

---

## 🎯 Business Objectives

* Analyze overall sales performance
* Identify best-selling and worst-selling pizzas
* Understand customer ordering patterns
* Discover peak sales days and months
* Evaluate sales contribution by category and pizza size
* Track key business KPIs

---

## 🛠️ Tools & Technologies

* **MySQL** – Data storage and analysis
* **SQL** – Data extraction and KPI calculations
* **Power BI** – Dashboard development and visualization
* **MySQL Server** – Database connection with Power BI

---

## 📂 Dataset

The dataset contains pizza sales transaction records, including:

* Order ID
* Order Date
* Pizza Name
* Pizza Category
* Pizza Size
* Quantity
* Unit Price
* Total Price

## 📈 Dashboard Insights

### Busiest Days

* Highest order volume observed during weekends
* Thursday, Friday, and Saturday recorded strong sales performance

### Busiest Months

* July generated the highest number of orders
* January also showed strong sales activity

### Category Performance

* Classic Pizza category contributed the highest sales volume
* Category-wise sales distribution was analyzed for business comparison

### Pizza Size Performance

* Large-sized pizzas generated the highest sales contribution

### Best Sellers

Identified top-performing pizzas based on:

* Revenue
* Orders
* Quantity Sold

### Worst Sellers

Identified low-performing pizzas based on:

* Revenue
* Orders
